What is CORTEX?

CORTEX is a minimal persistent context system for AI coding assistants. It lives inside your project's .claude/ directory and tells the agent what technologies you use, how the code is organised, what commands to run, and what decisions have been made.

📄 Single context file

Stack, structure, conventions, commands, and notes — all in context.md. The agent reads it once and has the full project map.

🧠 Memory that persists

Technical decisions, gotchas, and patterns documented in the same file. When you come back to the project, your agent remembers what it learned.

📦 Self-contained & portable

The entire system lives in .claude/cortex/. Install it with a single curl | bash in any project. It does not clutter the rest of your repo.

🤝 Plays nice with other systems

CORTEX is just another subdirectory in .claude/. It can coexist with other agent configuration systems without interference.

System structure

CORTEX v2 has exactly three files. Nothing else.

your-project/
├── CLAUDE.md ← "This project uses CORTEX — load .claude/cortex/SYSTEM.md"
└── .claude/
    └── cortex/ ← Everything CORTEX lives here
        ├── SYSTEM.md ← Agent behaviour instructions (do not edit)
        └── context.md ← Project data (edit this)

📋 CLAUDE.md

A single line referencing CORTEX. If the project already has a CLAUDE.md with other configurations, this line is simply appended.

/CLAUDE.md

⚙️ SYSTEM.md

Behaviour instructions for the agent. Tells it to load context.md, how to use the information, and how to keep it updated.

.claude/cortex/SYSTEM.md

📄 context.md

The heart of the system. Contains the tech stack, project structure, conventions, commands, and notes with decisions and gotchas.

.claude/cortex/context.md

How it works

The cycle is simple: the agent reads, uses, and maintains the context.

1

Agent starts a session

It reads CLAUDE.md, finds the CORTEX reference, and loads .claude/cortex/SYSTEM.md.

2

Loads project context

Follows SYSTEM.md's instruction and reads context.md. It now knows the stack, structure, conventions, and commands of the project.

3

Works with knowledge

Uses the structure to locate files without unnecessary exploration. Uses exact commands for build, test, and dev. Respects conventions and checks notes before acting on sensitive areas.

4

Keeps context updated

If it discovers a gotcha, makes a technical decision, or detects outdated context, it updates context.md silently. Knowledge accumulates with every session.

📝 context.md sections

  • Tech stack — technologies, versions, and purpose
  • Project structure — directory tree with descriptions
  • Conventions — naming, patterns, code rules
  • Commands — exact scripts for common tasks
  • Notes — decisions, gotchas, and dated observations

🔒 SYSTEM.md is off-limits

The agent instruction file is protected by convention. To change project context, edit context.md. To change agent behaviour, use .claude/settings.json.

Agent compatibility

CORTEX works with any AI agent that reads CLAUDE.md. Integration level varies by platform.

Agent Status Notes
Claude Code ✅ Full CLAUDE.md + instruction chaining
OpenCode ✅ Full CLAUDE.md + instruction chaining
Cursor ✅ Full CLAUDE.md supported
GitHub Copilot ✅ Full CLAUDE.md supported
Any agent ✅ Full Only needs to read CLAUDE.md and follow paths

CORTEX does not depend on slash commands or any platform-specific feature. It is just a CLAUDE.md file referencing another file. Any agent that can read instructions from a text file can use CORTEX.

Installation

A single command. No npm, gem, pip, or anything required.

🚀 Quick install (recommended)

1

Run the installer

The script downloads CORTEX, creates .claude/cortex/, and sets up the CLAUDE.md.

curl -sSL https://raw.githubusercontent.com/MaverickLBP/cortex/main/install.sh | bash
curl -sSL https://raw.githubusercontent.com/MaverickLBP/cortex/main/install.sh | bash -s -- /path/to/project
2

Describe your project

Edit .claude/cortex/context.md with your project's stack, structure, conventions, and commands. It is plain Markdown.

3

Start working

Your agent will automatically load the context when starting a session. Knowledge accumulates with every session.

📦 Manual installation

1

Clone the repository

git clone https://github.com/MaverickLBP/cortex.git /tmp/cortex
2

Copy the system into your project

mkdir -p your-project/.claude/cortex
cp /tmp/cortex/.claude/cortex/* your-project/.claude/cortex/
echo "→ Load .claude/cortex/SYSTEM.md for complete system instructions." >> your-project/CLAUDE.md
