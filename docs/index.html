¿Qué es CORTEX?

CORTEX es un sistema mínimo de contexto persistente para asistentes de código con IA. Vive dentro del directorio .claude/ de tu proyecto y le dice al agente qué tecnologías usas, cómo está organizado el código, qué comandos ejecutar y qué decisiones se han tomado.

📄 Un solo archivo de contexto

Stack, estructura, convenciones, comandos y notas — todo en context.md. El agente lo lee una vez y tiene el mapa completo del proyecto.

🧠 Memoria que perdura

Decisiones técnicas, gotchas y patrones documentados en el mismo archivo. Cuando vuelves al proyecto, tu agente recuerda lo que aprendió.

📦 Encapsulado y portable

Todo el sistema vive en .claude/cortex/. Se instala con un curl | bash en cualquier proyecto. No contamina el resto del repositorio.

🤝 Compatible con otros sistemas

CORTES es un subdirectorio más en .claude/. Puede coexistir con otros sistemas de configuración de agente sin interferencias.

Estructura del sistema

CORTEX v2 tiene exactamente tres archivos. Nada más.

tu-proyecto/
├── CLAUDE.md ← "Este proyecto usa CORTEX — carga .claude/cortex/SYSTEM.md"
└── .claude/
    └── cortex/ ← Todo CORTEX está aquí
        ├── SYSTEM.md ← Instrucciones al agente (no editar)
        └── context.md ← Datos del proyecto (editar)

📋 CLAUDE.md

Una línea que referencia a CORTEX. Si el proyecto ya tiene un CLAUDE.md con otras configuraciones, solo se añade esta línea.

/CLAUDE.md

⚙️ SYSTEM.md

Instrucciones de comportamiento para el agente. Le indica que cargue context.md, cómo usar la información, y cómo mantenerla actualizada.

.claude/cortex/SYSTEM.md

📄 context.md

El corazón del sistema. Contiene el stack, estructura del proyecto, convenciones, comandos y notas con decisiones y gotchas.

.claude/cortex/context.md

Cómo funciona

El ciclo es simple: el agente lee, usa y mantiene el contexto.

1

El agente inicia sesión

Lee CLAUDE.md, encuentra la referencia a CORTEX, y carga .claude/cortex/SYSTEM.md.

2

Carga el contexto del proyecto

Sigue la instrucción de SYSTEM.md y lee context.md. En ese momento conoce el stack, la estructura, las convenciones y los comandos del proyecto.

3

Trabaja con conocimiento

Usa la estructura para localizar archivos sin exploraciones innecesarias. Usa los comandos exactos para build, test y dev. Respeta las convenciones y consulta las notas antes de actuar en áreas sensibles.

4

Mantiene el contexto actualizado

Si descubre un gotcha, toma una decisión técnica, o detecta que el contexto está desactualizado, actualiza context.md en silencio. El conocimiento se acumula con cada sesión.

📝 context.md — secciones

  • Stack — tecnologías, versiones y propósito
  • Estructura — árbol de directorios con descripciones
  • Convenciones — naming, patrones, reglas de código
  • Comandos — scripts exactos para tareas comunes
  • Notas — decisiones, gotchas y observaciones con fecha

🔒 SYSTEM.md no se toca

El archivo de instrucciones del agente está protegido por convención. Si necesitas cambiar el contexto del proyecto, editas context.md. Si necesitas cambiar el comportamiento del agente, usas .claude/settings.json.

Compatibilidad con agentes

CORTEX funciona con cualquier agente de IA que lea CLAUDE.md. El nivel de integración varía según la plataforma.

Agente Estado Notas
Claude Code ✅ Completo CLAUDE.md + encadenamiento de instrucciones
OpenCode ✅ Completo CLAUDE.md + encadenamiento de instrucciones
Cursor ✅ Completo CLAUDE.md soportado
GitHub Copilot ✅ Completo CLAUDE.md funcional
Cualquier agente ✅ Completo Solo necesita leer CLAUDE.md y seguir rutas

CORTEX no depende de slash commands ni de ninguna característica específica de plataforma. Es solo un archivo CLAUDE.md que referencia a otro archivo. Cualquier agente que pueda leer instrucciones de un archivo de texto puede usar CORTEX.

Instalación

Un solo comando. No requiere npm, gem, pip, ni nada.

🚀 Instalación rápida (recomendada)

1

Ejecuta el instalador

El script descarga CORTEX, crea .claude/cortex/ y configura el CLAUDE.md.

curl -sSL https://raw.githubusercontent.com/MaverickLBP/cortex/main/install.sh | bash
curl -sSL https://raw.githubusercontent.com/MaverickLBP/cortex/main/install.sh | bash -s -- /ruta/a/tu-proyecto
2

Describe tu proyecto

Edita .claude/cortex/context.md con el stack, estructura, convenciones y comandos de tu proyecto. Es un archivo Markdown plano.

3

Empieza a trabajar

Tu agente cargará automáticamente el contexto al iniciar sesión. El conocimiento se acumula con cada sesión.

📦 Instalación manual

1

Clona el repositorio

git clone https://github.com/MaverickLBP/cortex.git /tmp/cortex
2

Copia el sistema a tu proyecto

mkdir -p tu-proyecto/.claude/cortex
cp /tmp/cortex/.claude/cortex/* tu-proyecto/.claude/cortex/
echo "→ Carga .claude/cortex/SYSTEM.md" >> tu-proyecto/CLAUDE.md
