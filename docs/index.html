What is CORTEX?

A dynamic knowledge system that lives in .claude/cortex/ and provides your AI agent with a complete, living map of your project.

map Living Knowledge Map

MAP.md documents every directory and file in your project. The agent keeps it updated as you work.

autorenew Auto-Maintained

The agent updates MAP.md silently as part of normal work. No manual documentation upkeep required.

share Shared via Git

CORTEX files are normal project files. They appear in commits, pull requests, and code reviews. Knowledge travels with the repo.

extension Agent-Agnostic

Works with Claude Code, OpenCode, Cursor, GitHub Copilot, and any agent that reads CLAUDE.md.

How It Works

Three steps to give your AI agent persistent project knowledge.

1
Install

Run a single curl command. CORTEX sets up .claude/cortex/ and configures CLAUDE.md automatically.

curl -sSL https://raw.githubusercontent.com/MaverickLBP/cortex/main/install.sh | bash
2
Initialize

The agent scans your project structure, detects the tech stack, and builds MAP.md from scratch.

/cortex-init
3
Work

The agent consults MAP.md on every session — finding files, understanding structure, and keeping the map updated.

/cortex-view-map

Commands

Three commands to manage your project's knowledge layer.

init cortex-init

First-run project scanner. Walks the entire directory tree, detects the tech stack, and generates MAP.md from scratch.

Claude Code: /cortex-init
OpenCode: run cortex-init

update cortex-update

Incremental maintenance. Preserves all existing content and only adds, removes, or updates what has changed since last scan.

Claude Code: /cortex-update
OpenCode: run cortex-update

view cortex-view-map

Display the current knowledge map. Supports optional path filter to show only a specific section of the project.

Claude Code: /cortex-view-map
OpenCode: run cortex-view-map

Compatibility

CORTEX works with any agent that reads CLAUDE.md.

Agent Support Notes
Claude Code Slash commands, CLAUDE.md, hooks
OpenCode Natural language commands, CLAUDE.md
Cursor CLAUDE.md supported
GitHub Copilot CLAUDE.md functional, no slash commands
Any agent Reads CLAUDE.md and follows instructions

Installation

One command to add CORTEX to any project.

Quick Install
curl -sSL https://raw.githubusercontent.com/MaverickLBP/cortex/main/install.sh | bash

Or install to a specific directory:

curl -sSL https://raw.githubusercontent.com/MaverickLBP/cortex/main/install.sh | bash -s -- /path/to/project
Manual Install

Clone the repository and copy the .claude/cortex/ directory into your project:

git clone https://github.com/MaverickLBP/cortex.git /tmp/cortex
cp -r /tmp/cortex/.claude your-project/
rm -rf /tmp/cortex
After Installing
  1. Start a session with your AI agent
  2. Run /cortex-init to scan your project
  3. Run /cortex-view-map to see the knowledge map
  4. Use /cortex-update after structural changes
