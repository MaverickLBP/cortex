## 📁 .cortex/

_CORTEX knowledge root (agent-agnostic). Always committed. Contains agent instructions, knowledge map, commands, and scanner script._

- `SYSTEM.md` → **Agent behaviour instructions.** Do not edit manually. Defines how the agent should load, use and maintain MAP.md. Version 4.0.0.
- `MAP.md` → **This file. Project knowledge map.** Describes the entire project structure: what is in each folder and what each file does. Generated by `cortex-init` and maintained by the agent automatically.

### 📁 .cortex/commands/

_Command definitions (agent-agnostic templates). The installer copies these to `.claude/commands/` and/or `.opencode/commands/` depending on the chosen agent(s). Commands are user-triggered slash commands, not model-triggered skills._

- `cortex-init.md` → **`cortex-init` command definition.** First-run only. Describes the procedure to generate MAP.md from scratch: detect tech stack, run scanner, document every directory, write MAP.md, preserve existing notes.
- `cortex-update.md` → **`cortex-update` command definition.** Maintenance command. Updates MAP.md when project structure changes or format evolves. Preserves all existing content.
- `cortex-view-map.md` → **`cortex-view-map` command definition.** Instructs the agent to read and display MAP.md. Supports optional path filter.

### 📁 .cortex/scripts/

_Utility scripts for CORTEX operations._

- `cortex-init.sh` → **Project scanner.** Bash script that walks the project generating a complete directory and file tree. Excludes `.git`, `node_modules`, `dist`, `build`, `.next`, `out`, `target`, `vendor`, `_build`, `.venv`, `__pycache__`, `.cache`. Usage: `bash .cortex/scripts/cortex-init.sh`.

## 📁 .claude/

_Claude Code agent configuration. Only present when CORTEX is installed for Claude Code._

- `settings.json` → **Committed** Claude Code settings. Registers the `cortex-session.sh` SessionStart hook. Per-user overrides go in `.claude/settings.local.json` (gitignored).

### 📁 .claude/hooks/

- `cortex-session.sh` → **SessionStart hook template.** Reads `cwd` from the hook JSON payload, detects workspace mode (`.cortex-workspace.json` marker), and emits `additionalContext` with SYSTEM.md content + order to load MAP.md. Exit 0 silently if nothing applies or `jq` is missing.

### 📁 .claude/commands/

_Slash commands for Claude Code. Copied from `.cortex/commands/` by the installer._

- `cortex-init.md` → Copy of `.cortex/commands/cortex-init.md`
- `cortex-update.md` → Copy of `.cortex/commands/cortex-update.md`
- `cortex-view-map.md` → Copy of `.cortex/commands/cortex-view-map.md`

**2026-06-18 — v4.0.0 breaking change: knowledge moved from `.claude/cortex/` to `.cortex/`**
Knowledge is now in `.cortex/` (agent-agnostic). Agent-specific config lives in `.claude/` (Claude Code) or `.opencode/` + `opencode.json` (OpenCode). Enforcement via native mechanisms: SessionStart hook (Claude Code) and `instructions` field (OpenCode). CLAUDE.md is no longer used for enforcement.
