## 📁 .claude/cortex/

_CORTEX root directory. The entire knowledge system is self-contained here: agent instructions, knowledge map, commands and scripts._

- `SYSTEM.md` → **Agent behaviour instructions.** Do not edit manually. Defines how the agent should load, use and maintain MAP.md. Version 3.1.0.
- `MAP.md` → **This file. Project knowledge map.** Describes the entire project structure: what is in each folder and what each file does. Generated by `cortex-init` and maintained by the agent automatically.

### 📁 .claude/cortex/commands/

_Custom commands the agent can execute. Claude Code exposes them as slash commands (e.g. `/cortex-init`). OpenCode runs them with "run <command>"._

- `cortex-init.md` → **`cortex-init` command definition.** First-run only. Describes the procedure the agent must follow to generate MAP.md from scratch:
  1. Step 0: Detect tech stack (package.json, go.mod, Dockerfile, etc.)
  2. Run `scripts/cortex-init.sh` to get the directory tree
  3. Walk through each directory, exploring and documenting its contents
  4. Write the complete MAP.md with Tech Stack table + directory entries
  5. Preserve existing notes if any
- `cortex-update.md` → **`cortex-update` command definition.** Maintenance command. Updates MAP.md when project structure changes or format evolves. Preserves all existing content, adds/removes entries as needed, detects missing sections.
- `cortex-view-map.md` → **`cortex-view-map` command definition.** Instructs the agent to read and display MAP.md to the user. Supports optional path filter (e.g. `cortex-view-map src/api`).

### 📁 .claude/cortex/scripts/

_Utility scripts for CORTEX operations that require logic outside the agent._

- `cortex-init.sh` → **Project scanner.** Bash script that walks the project generating a complete directory and file tree. Excludes `.git`, `node_modules`, `dist`, `build`, `.next`, `out`, `target`, `vendor`, `_build`, `.venv`, `__pycache__`, `.cache`. The agent uses this output to build MAP.md. Usage: `bash .claude/cortex/scripts/cortex-init.sh`.
