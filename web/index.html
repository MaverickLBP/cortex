Technical Experience

Un sistema de memoria persistente para asistentes de desarrollo con IA. Decisiones, patrones, arquitectura y estado de sesión — todo lo que tu agente necesita saber, siempre disponible.

🧠 Memoria persistente ⚡ Autónomo 🔌 Agnóstico de agente 📋 Sesiones

¿Qué es CORTEX?

CORTEX es un sistema de conocimiento que vive dentro del directorio .claude/ de tu proyecto. Proporciona contexto persistente a cualquier agente de IA — Claude Code, OpenCode, Cursor, GitHub Copilot — a través del archivo CLAUDE.md.

🧠 Memoria que perdura

Las decisiones técnicas, los gotchas y los patrones no se pierden entre sesiones. Cuando vuelves, tu agente recuerda exactamente dónde lo dejaste.

⚡ Autónomo

El agente registra decisiones, deuda técnica y cambios de alcance sin que tengas que pedírselo. CORTEX se alimenta solo mientras trabajas.

🌐 Agnóstico de agente

Funciona con Claude Code, OpenCode, Cursor, GitHub Copilot y cualquier agente que lea CLAUDE.md. No estás atado a una plataforma.

📋 Gestión de sesiones

Crea, guarda, carga y cierra sesiones de trabajo con contexto completo. Ideal para tareas largas, revisión de PRs o contextos de investigación.

Estructura del sistema

CORTEX se organiza en cinco dominios — MAP, MEMORY, OPS, STATE y SESSIONS — más la capa de comandos y configuración.

tu-proyecto/
├── CLAUDE.md ← Carga CORTEX vía .claude/CLAUDE.md
└── .claude/ ← Sistema CORTEX
    ├── CLAUDE.md ← Instrucciones completas del sistema
    ├── settings.json ← Hooks de Claude Code
    ├── commands/ ← Slash commands
    │   ├── cortex-init.md
    │   ├── cortex-preflight.md
    │   ├── cortex-sync.md
    │   ├── cortex-onboard.md
    │   ├── cortex-session-*.md
    │   └── ...
    └── cortex/ ← Base de conocimiento persistente
        ├── map/ ← Arquitectura y dependencias
        ├── memory/ ← Decisiones, gotchas, patrones
        ├── ops/ ← Entorno, workflows, onboarding
        ├── state/ ← Scope y deuda técnica
        └── sessions/ ← Estado y contexto de sesiones

Componentes del sistema

Cada dominio tiene un propósito específico dentro del ecosistema CORTEX.

🗺️ MAP — Conocimiento estructural

Generado automáticamente por cortex-init. Describe la arquitectura del proyecto, sus dependencias y módulos.

🏗️ architecture.md

Stack tecnológico, estructura de directorios, puntos de entrada, flujo general y módulos principales del proyecto.

.claude/cortex/map/architecture.md

📦 dependencies.md

Dependencias principales del proyecto, versiones y propósito de cada una dentro del contexto del proyecto.

.claude/cortex/map/dependencies.md

🧠 MEMORY — Memoria activa

Actualizado autónomamente por el agente. Siempre se carga al inicio de la sesión.

📝 decisions.md

Decisiones técnicas importantes: qué se decidió, por qué, y qué alternativas se descartaron. Evita repetir discusiones.

.claude/cortex/memory/decisions.md

⚠️ gotchas.md

Trampas conocidas, comportamientos inesperados y bugs no obvios con sus soluciones. El agente las revisa antes de trabajar en áreas sensibles.

.claude/cortex/memory/gotchas.md

🔁 patterns.md

Patrones y convenciones del proyecto. El agente los respeta para mantener consistencia en el código nuevo.

.claude/cortex/memory/patterns.md

⚙️ OPS — Operaciones

Documentación operativa del proyecto. Generada por cortex-init.

🔐 environment.md

Variables de entorno requeridas y opcionales, servicios externos, diferencias entre entornos (dev / staging / prod).

.claude/cortex/ops/environment.md

🛠️ workflows.md

Comandos de instalación, desarrollo, test, build y deploy. Cualquier proceso manual relevante.

.claude/cortex/ops/workflows.md

📖 onboarding.md

Documento generado por cortex-onboard para que un nuevo desarrollador se ponga al día rápidamente.

.claude/cortex/ops/onboarding.md

📊 STATE — Estado del proyecto

Actualizado autónomamente. Refleja la salud y el alcance actual del proyecto.

🎯 scope.md

Control de alcance de tareas. El agente registra automáticamente cuando una tarea se desvía de lo pedido y alerta al usuario.

.claude/cortex/state/scope.md

💳 tech-debt.md

Deuda técnica: workarounds, soluciones temporales, y el camino para resolverlas correctamente cuando se aborde.

.claude/cortex/state/tech-debt.md

📁 SESSIONS — Sesiones de trabajo

Gestión completa de sesiones: crear, guardar, cargar, listar y cerrar.

📋 index.md

Registro central de todas las sesiones. Indica cuál está activa y muestra el historial con estado, código y fechas.

.claude/cortex/sessions/index.md

📄 [código]/state.md

Estado exacto de una sesión: último paso completado, archivos activos, blockers, y resumen del progreso.

.claude/cortex/sessions/S001/state.md

📄 [código]/context.md

Contexto detallado de la sesión: decisiones específicas, hallazgos y notas tomadas durante la sesión.

.claude/cortex/sessions/S001/context.md

Comandos del sistema

CORTEX expone comandos que pueden invocarse como slash commands en Claude Code o mediante lenguaje natural en cualquier agente.

Comando Claude Code Lenguaje natural Descripción
cortex-init /cortex-init "Inicia CORTEX" Explora el proyecto y genera el knowledge base desde cero
cortex-preflight /cortex-preflight "Preflight" / "revisión previa" Revisa conocimiento relevante antes de empezar una tarea
cortex-sync /cortex-sync "Sincroniza CORTEX" Re-sincroniza MAP y OPS tras cambios estructurales
cortex-onboard /cortex-onboard "Genera onboarding" Crea guía de onboarding para nuevo desarrollador
cortex-session-new /cortex-session-new [nombre] "Nueva sesión: [nombre]" Crea una nueva sesión de trabajo
cortex-session-save /cortex-session-save "Guarda sesión" / "pausa" Persiste el estado exacto de la sesión activa
cortex-session-load /cortex-session-load [código] "Carga sesión [código]" Restaura el contexto de una sesión pausada
cortex-session-list /cortex-session-list "Lista sesiones" Muestra todas las sesiones con su estado
cortex-session-close /cortex-session-close "Cierra sesión" Marca la sesión activa como completada

Los archivos en .claude/commands/*.md contienen las instrucciones detalladas de cada comando y sirven como documentación de referencia para el agente.

Compatibilidad con agentes

CORTEX funciona con cualquier agente de IA que lea CLAUDE.md. El nivel de integración varía según la plataforma.

Agente Estado Notas
Claude Code ✅ Completo Slash commands, settings hooks, CLAUDE.md
OpenCode ✅ Completo Lenguaje natural, CLAUDE.md
Cursor ✅ Completo CLAUDE.md soportado
GitHub Copilot ⚠️ Parcial CLAUDE.md funcional, sin slash commands
Cualquier agente 🟢 Básico Lee CLAUDE.md y sigue instrucciones de ruta

Instalación

Dos modos de instalar CORTEX en tu proyecto.

🐚 Instalación rápida (recomendada)

1

Ejecuta el instalador

El script descarga CORTEX y lo instala en el directorio actual o en el que especifiques.

curl -sSL https://raw.githubusercontent.com/MaverickLBP/cortex/main/install.sh | bash
curl -sSL https://raw.githubusercontent.com/MaverickLBP/cortex/main/install.sh | bash -s -- /ruta/a/tu-proyecto
2

Inicia una sesión con tu agente IA

CORTEX se activa automáticamente al leer el CLAUDE.md.

3

Genera la base de conocimiento inicial

Opcional: ejecuta cortex-init para explorar el proyecto y generar el knowledge base.

/cortex-init   # Claude Code
"Inicia CORTEX"  # Cualquier agente

📦 Instalación manual

1

Clona el repositorio

git clone https://github.com/MaverickLBP/cortex.git /tmp/cortex
2

Copia los archivos a tu proyecto

cp /tmp/cortex/CLAUDE.md .
cp -r /tmp/cortex/.claude .
rm -rf /tmp/cortex

🔗 Solo el loader (proyecto existente)

Si tu proyecto ya tiene un CLAUDE.md, añade esta línea al inicio: 

→ Carga .claude/CLAUDE.md para las instrucciones completas del sistema.

Luego copia el directorio .claude/ manualmente como se describe arriba.
